# Sprint Retrospectives (RETRO.md)

Honest sprint-by-sprint retrospectives documenting engineering lessons learned across the **MohanMart** capstone lifecycle.

---

### Sprint 0 (Jul 2026): Project Setup, Schema Design & HikariCP Foundation
- **One-line summary**: Designing the normalized 6-table DDL schema (`users`, `products`, `orders`, `order_items`, `cart_items`, `reviews`) and HikariCP `AppContextListener` upfront eliminated connection leaks, though aligning H2 and PostgreSQL identity/constraint syntax required switching to ANSI `GENERATED BY DEFAULT AS IDENTITY`.

---

### Sprint 1 (Aug 2026): DAO Layer, Service Layer & Transactional Checkout
- **One-line summary**: Raw JDBC `PreparedStatement` DAOs and manual ACID transaction boundaries (`setAutoCommit(false)` / `commit()` / `rollback()`) in `OrderServiceImpl` prevented partial stock deductions, and isolating each DAO test with an in-memory H2 reset (`BaseDAOTest`) kept the test suite deterministic.

---

### Sprint 2 (Sep 2026): Security Pipeline, RBAC & Classical JSP UI
- **One-line summary**: Centralizing authentication in `AuthFilter` and token verification in `CsrfFilter` kept servlets thin, while escaping all JSP expressions with `<c:out>` and testing against an embedded Tomcat 9 instance caught JSP rendering and session-cookie edge cases early.

---

### Sprint 3 / Final Sprint (Oct 2026): AI Chatbot (O4), Order Workflow (O2) & Cloud Deployment
- **One-line summary**: Decoupling the AI assistant behind `ChatProvider` + `ChatProviderFactory` (`GeminiChatProvider` with an 8-second timeout, PII redaction, and automatic failover to `MockChatProvider`) plus a 10-messages/minute session rate limiter ensured the chatbot remained fast, private, and resilient even when offline or rate-limited.
